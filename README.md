# 🎓 Campus Bazaar

A peer-to-peer campus marketplace designed exclusively for university students. This is a Full-Stack Web Application built for our Semester 3 DBMS Project.

## 🛠️ Tech Stack
* **Frontend**: HTML5, CSS3, Vanilla JavaScript
* **Backend**: Node.js, Express.js
* **Database**: MySQL
* **Authentication**: bcryptjs (Password Hashing)

## 📋 Prerequisites
Before you begin, ensure you have the following installed on your computer:
1. [Node.js](https://nodejs.org/)
2. [MySQL Server & MySQL Workbench](https://dev.mysql.com/downloads/workbench/) (or phpMyAdmin)
3. [Git](https://git-scm.com/)
